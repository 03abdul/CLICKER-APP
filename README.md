# TASK-CLICKER

This is a simple Clicker project built using **HTML**, **CSS**, and **JavaScript**.

In this project, there are **10 buttons**, each labeled with a number from 1 to 10. When you click a button, the corresponding number is displayed on the screen.

---

### 🔧 Technologies Used:
- HTML
- CSS
- JavaScript

---

### 📱 Responsive Design
The app is fully responsive and works on both **desktop** and **mobile** devices.

---

### 🔒 Security Notice
This is a safe, personal project. It does not collect any data, store any information, or use external scripts.
